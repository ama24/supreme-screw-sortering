# 01 catalogue

The single source of truth for every part the dataset can contain: families with per-size dimension tables (DIN/ISO), length lists and allowed finishes, expanded into parts in code, plus a validator, classes.yaml generator and the screwsynth-catalogue CLI.

- **Inputs:** configs/config.yaml (catalogue section)
- **Outputs:** configs/catalogue.yaml, configs/classes.yaml, tools/catalogue/VERIFY.md
