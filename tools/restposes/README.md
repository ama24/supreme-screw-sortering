# 04 restposes

Precomputes how each part naturally rests on a flat plate (trimesh stable poses, merged over yaw, thresholded, with per-family overrides and an optional physics drop validation), including the axis heights used later for parallax correction.

- **Inputs:** data/assets/<part_id>/ (tool 02)
- **Outputs:** data/rest_poses/<part_id>.json, summary table, contact sheet
- **Guide:** [docs/prompts/04_restposes.txt](../../docs/prompts/04_restposes.txt)
